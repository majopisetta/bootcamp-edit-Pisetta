# Proyecto Integrador
* el proyecto integrador es basicamente un CRUD
* El alumno es una entidad de negocio / dominio

* Alumno
    * Id
    * Nombre
    * Apellido
    * Cantidad_Cursos

* Todo el registro de los alumnos lo vamos a guardar en MEMORIA (si cierro la app pierdo todo)

* Primero vamos a hacer una versión consola y despues la version escritorio como pide el enunciado. 

* Para cada alumno individual voy a generar un diccionario y a la vez para la base de datos en memoria la voy a tener en una lista de diccionarios.
